- 所有共享状态类使用 @MainActor + @Observable 宏声明，并通过 @Bindable 在 SwiftUI 中订阅，保证主线程安全与响应式更新。
- AppDelegate 集中组装 Store、Controller 与 Actions，UI 层仅通过闭包回调（UsageActions）触发业务逻辑，禁止 View 直接调用 Service。
- 异步任务统一使用 Task { @MainActor ... } 或 await MainActor.run { ... } 切回主线程更新 UI，避免在主线程阻塞 I/O。
- JSON 序列化统一通过 JSONEncoder.tomo / JSONDecoder.tomo 扩展，固定 ISO8601 日期策略与 prettyPrinted + sortedKeys 输出格式。
- Store 的持久化路径统一基于 FileManager.applicationSupportDirectory 下的 Tomo 子目录，并以 .json 文件命名存储。
- Shell 脚本统一使用 set -euo pipefail、trap 清理临时文件、PlistBuddy 读取 Info.plist 版本号，保持构建流程健壮性。
