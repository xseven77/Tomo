应用采用 SPM 可执行包结构（Package.swift），目标为 macOS 14+，链接 sqlite3 库。入口由 ApplicationMain.swift 的 @main 枚举提供，支持 --probe-chatgpt-apis 命令行模式走 CLI 探测流程；正常模式通过 AppDelegate 初始化 NSApplication 并进入事件循环。

AppDelegate 作为装配中心，组合多个 Store（UsageSnapshotStore、AppSettingsStore、CodexActivityStore、PetFrameStore、CompanionStatsStore）与控制器（StatusBarController、DetachedWindowController、AppUpdateController），并通过 UsageActions 回调在 UI 层与业务层之间解耦。UI 全部使用 SwiftUI，以 CompanionDashboardView 为主视图，根据 settings.dashboardOrientation 切换横版/竖版布局。

数据层遵循单向流：Service（如 CodexUsageService）负责网络与持久化，Store 通过 @Observable 宏暴露响应式状态，SwiftUI View 通过 @Bindable 订阅更新。状态变更由 AppDelegate 协调各 Store 同步，避免跨层直接调用。

Resources/ 包含 Info.plist、AppIcon、宠物精灵图与 SVG 资源；dist/ 存放打包产物；scripts/ 与根级 shell 脚本负责构建、签名、生成 ZIP/DMG。
