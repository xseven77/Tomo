采用 Next.js 16 App Router 的单页结构：`src/app/layout.tsx` 定义根布局（注入 Geist 字体、ThemeProvider、主题初始化脚本与全局元数据），`src/app/page.tsx` 作为首页路由，通过 `Promise.all` 并行拉取 GitHub 仓库与 Release 数据后渲染各区块组件。
- 组件层（`src/components/`）按页面区块拆分：Header、Hero、Features、HowItWorks、GitHubRepoSection、GitHubReleasesSection、DownloadCTA、Footer、JsonLd、MenuBarPreview、ThemeToggle、ThemeProvider。
- 配置与工具层（`src/lib/`）：`site.ts` 集中站点常量（名称、描述、SEO keywords、GitHub 链接），`metadata.ts` 提供 `createMetadata` 工厂函数统一生成 OpenGraph/Twitter/robots/manifest 等 SEO 元数据，`github.ts` 封装 GitHub API 调用。
- 样式通过 Tailwind CSS v4 + PostCSS 处理，主题由 `lib/theme/` 下的脚本在 `<head>` 中内联执行以避免闪烁。
- 依赖方向单向：page → components → lib；组件不直接访问 Next 路由或环境变量，仅通过 `@/lib/*` 获取数据与配置。
