根仓库以 `app/` 为边界组织两个独立产物：`app/Tomo/` 是 Swift Package Manager + SwiftUI 的 macOS 菜单栏伴侣应用，`app/landing/` 是 Next.js 静态站点；两者通过 README 中的下载链接与 GitHub Releases 关联，由顶层 `PROJECT.md` 统一记录技术边界与发布流程。`docs/` 存放 UI 方案、Dashboard 方向切换、陪伴状态、Liquid Glass 主题等实现记录，被 README 的「进一步阅读」索引。`.gitignore` 与 `docker/landing/` 分别约束忽略规则与落地页容器部署配置，三者共同构成「应用 → 文档 → 展示」的单向依赖关系。
