### Tomo
- 定义：项目核心产品名，一款原生 macOS 菜单栏应用程序，为 Codex（OpenAI 的 AI 编程助手）用户提供实时任务状态、Pet 同步、额度与订阅周期的可视化监控。应用以菜单栏胶囊形式提供"一瞥即知"的信息展示，同时支持独立窗口查看更详细的数据。
- 别名：Tomo App、菜单栏应用

### Pet 系统
- 定义：Tomo 中的虚拟宠物功能，支持内置 Pet 和自定义 Pet。用户可以在设置中选择 Pet，应用会将选择写入 Codex 配置实现双向同步。Pet 资源存储在 `~/.codex/pets` 目录，每个 Pet 需要包含 pet.json 配置文件和 spritesheet.webp 图集文件。
- 别名：虚拟宠物、Pet 动画、spritesheet

### 额度窗口
- 定义：ChatGPT 的使用配额限制周期，包括主额度窗口（primary_window）和次级额度窗口（secondary_window）。额度窗口不再假定固定时间，而是根据 limit_window_seconds 动态计算，常见为 5 小时和周额度。当 total == 0 时视为不可展示。
- 别名：quota window、rate_limit、usage window

### 重置券
- 定义：ChatGPT 提供的额度重置凭证，通过 `/backend-api/wham/rate-limit-reset-credits` 接口获取。每张重置券包含过期时间、来源信息和状态，过期的券不会在界面显示。重置券是可选请求，失败不影响主额度数据的获取。
- 别名：reset credits、reset coupon、额度券

### 陪伴统计
- 定义：记录用户与 Codex 一起工作的时间统计，每 30 秒结算一次有效活动时长，单次最多计 90 秒以避免 Mac 休眠后夸大离线时间。统计数据保存在 companion_stats.json 文件中，每日清零重新累计。
- 别名：companion stats、陪伴时间、工作统计

### ad-hoc 签名
- 定义：当前应用的代码签名方式，使用 ad-hoc 签名生成 .app、.zip 和 .dmg 安装包。这种方式不需要 Apple Developer 证书，但尚未完成 Apple notarization，首次打开可能需要手动允许。未来计划升级到 Apple Developer ID 签名和 notarization。
- 别名：ad-hoc 打包、未公证、本地签名

### wham 端点
- 定义：ChatGPT Web 端的非公开 API 端点，主要用于获取用量和订阅信息。包括 `/backend-api/wham/usage`（主/次级额度）、`/backend-api/wham/rate-limit-reset-credits`（重置券）等。这些端点不是公开稳定 API，所有请求和解析集中在特定服务中处理。
- 别名：wham API、后端 API、用量接口

### 状态栏圆灯
- 定义：菜单栏前置圆灯，用于显示当前优先级最高的 Codex 任务状态。不同颜色对应不同状态：灰色（空闲）、紫色（思考）、蓝色（执行）、青色（检查）、橙色（等待确认）、绿色（完成）、红色（中止）。圆灯颜色与提醒色相互独立。
- 别名：status light、任务圆灯、菜单栏指示灯
