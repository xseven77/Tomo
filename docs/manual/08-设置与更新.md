# 08 - 设置、更新与生命周期

本章介绍设置窗口五大页面、全部设置项与持久化键、应用自动更新流程、启动/退出行为与构建分发脚本。

---

## 1. 设置窗口结构

入口：主窗口/仪表盘右上角齿轮（`openSettingsWindow`，`AppDelegate.swift:397+`；窗口类 `SettingsWindowController`，`DetachedWindowController.swift:821`）。
左侧/顶部分 5 个 Tab（`SettingsViews.swift:13-53`）：

| Tab | 标题 | 副标题 | 内容 |
|---|---|---|---|
| general | 通用 | 更新、外观、布局与刷新 | 主题、刷新间隔、轮播间隔、静默启动、登录项、置顶、版本与更新 |
| accounts | 账户池 | 管理本机账号与 API Key | 四类连接 CRUD、选择/停用、明文 Key（认证后）——详见 02 章 |
| agents | Agents 与 Hooks | 接入并管理本地 Coding Agent | 5 个 agent 安装探测 + 安装指引弹窗 —— 详见 03 章 |
| gateway | Gateway | 本地多协议 LLM 网关与遥测 | 网关开关、自动启动、打开网关窗口 —— 详见 05 章 |
| pet | 状态栏与 Pet | 菜单栏、任务浮窗与 Pet | 宠物选择、波浪、刘海、独立 Pet —— 详见 04/06 章 |

## 3. 应用自动更新（AppUpdateService）

- 源：GitHub Releases —— `https://api.github.com/repos/xseven77/Tomo/releases/latest`（`AppUpdateService.swift:38-41`），无 Sparkle。
- 状态机 `AppUpdatePhase`：idle → checking → upToDate / available → downloading → installing → relaunch / failed（`:5-24, 111-154`）。
- 版本比较用语义化 `compareVersions`（`:125-129`）。
- **下载即装**：下载 Release 的 **.dmg** 附件，带进度百分比（`DownloadProgressSession` URLSession delegate，`:400+`）→ 挂载 DMG → 复制替换 `Tomo.app` → 自动重启（`relaunchAfterInstall`，`:148-149`）。
- UI 入口：设置「通用」页更新区块（检查更新/立即安装/打开 Releases 页 `openReleasesPage`，`:107-109`）。

## 4. 应用生命周期（AppDelegate / ApplicationMain）

### 启动序列（`ApplicationMain.swift:10-24` → `AppDelegate.swift:27-207`）
1. CLI 短路：带 `--probe-chatgpt-apis` 参数则执行 API 探测后退出。
2. 注册内置字体（carter-one）。
3. `setActivationPolicy(.accessory)`：默认无 Dock 图标、纯菜单栏应用。
4. 依次：`GatewaySupervisor.shared.start()`（网关后台服务先于任何 UI，`:29-32`）→ 应用主题 → 挂接全部设置回调（刷新定时器、轮播、主题、置顶、刘海目标/拖拽、宠物、选中连接投影，`:34-83`）→ 绑定 Gateway 与活动 store（`:84-107`）。
5. 构建 `UsageActions`（刷新/登录/断开/打开主窗/打开 Gateway/打开用量网页 `https://chatgpt.com/codex/settings/usage`/退出，`:109-138`）。
6. 创建 `StatusBarController`，启动自动刷新 + 轮播定时器、`CodexActivityStore.start()`、agent socket 监听、伴侣统计、`CodexPetSelectionMonitor`（`:141-195`）。
7. 加载宠物目录并与 Codex 同步选中；按需开主窗；0.5s 后重申独立 Pet 可见性（防 WindowServer 面板重建竞态，`:196-205`）；首轮静默额度刷新。

### 退出（`:209-216`）
停 Codex app-server 子进程、agent socket、活动轮询、统计、帧动画、宠物监听。Gateway 子进程随 App 终止。

### 其他
- Dock 图标点击（reopen）重开主窗（`:438`）。
- 系统深浅色切换自动跟随（`applicationDidUpdate → refreshSystemAppearanceIfNeeded`，`:218-220`）。

## 5. 构建与发布脚本

| 脚本 | 作用 |
|---|---|
| `package_app.sh` | `swift build -c release` → 组装 `dist/Tomo.app`（主二进制进 `Contents/MacOS/`；`TomoAgentBridge` 与 Rust 网关 `TomoGateway` 进 `Contents/Helpers/`；图标/宠物/字体资源，`package_app.sh:133-139`）→ 校验 `GeminiOAuthConfig.plist`（`--validate-oauth-config` 只校验）→ ad-hoc 签名（`codesign --deep --sign -`）→ `hdiutil` 出 zip + dmg。支持 `TOMO_GEMINI_OAUTH_CONFIG_PLIST` / `TOMO_GEMINI_OAUTH_CLIENT_ID` 环境变量注入配置。 |
| `package_local.sh` | 本机专用（被 git 忽略）：注入本机 OAuth 配置后调用 package_app.sh。`rebuild_and_run.sh` 即走此路径，然后 `pkill -x Tomo && open dist/Tomo.app`。 |
| `release_app.sh` / `release_local.sh` | 版本号来自 `Resources/Info.plist`（CFBundleShortVersionString/CFBundleVersion），构建 zip/dmg 后用 `gh release create/upload` 发布到 GitHub Release（支持 `--publish-only` 只发布已有产物、失败回滚版本号）。 |
| `scripts/run_chatgpt_api_probe.sh` | 以 `--probe-chatgpt-apis` 跑额度端点探测。 |

测试：`Tests/TomoTests/` 共 10 个套件（网关、5 个 agent activity service、notch 拖拽、hook 管理、多 agent 模型、独立宠物窗、综合）。
