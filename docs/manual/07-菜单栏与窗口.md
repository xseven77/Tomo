# 07 - 菜单栏、刘海面板与窗口

本章介绍 Tomo 的三个主要 UI 表面：状态栏胶囊、刘海（Notch）面板、分离主窗口，以及它们的交互与降级逻辑。

---

## 1. 状态栏胶囊（StatusBarController）

- **左键单击图标**：直接打开/唤起分离主窗口（`DetachedWindowController`），弹出在图标所在屏幕（`StatusBarController.swift:397-406`）。Tomo 没有传统右键下拉菜单，所有操作入口都在主窗口与设置窗口内。
- **标题内容**：`refreshStatusTitle()`（`StatusBarController.swift:418`）根据当前选中连接的额度快照渲染文字（`statusBarQuotaText`，如剩余额度百分比、窗口标签）。
- **活动波浪动画**：任一 agent 处于活动态（`showsActivityWave`）时，胶囊背景出现 30fps Canvas 波浪（`ActivityCapsuleWave`，`StatusBarController.swift:166-200`）；波浪开关与配色由设置项 `statusBarWaveEnabled` / `statusBarWaveColorMode` 控制。
- **悬停浮窗**：鼠标悬停图标片刻弹出 `PetHoverPanelController` 宠物+任务悬浮面板；移动鼠标进入浮窗的路径由 `HoverSafeTriangle`（假想三角区）保护，不会中途丢失悬停（`StatusBarController.swift:1025`）。
- **降级关系**：当刘海面板在该屏启用时，状态栏图标自动隐藏（`statusItem.isVisible = !notchEnabled`，`StatusBarController.swift:636-637`）——刘海胶囊成为该屏唯一表面；若目标屏没有物理刘海，则由 `LegacyCapsulePanelController` 在菜单栏区域绘制同款胶囊（`NotchDisplayManagement.swift:59`）。

## 2. 刘海胶囊面板（NotchCapsulePanel）

### 2.1 形态
- 一个无边框、非激活式 `NSPanel`（`NotchOverlayPanel`），贴合屏幕顶部刘海：收起态高度=刘海/状态栏高度，宽度=刘海宽度+左右翼；展开时以弹性动画（spring 0.42/0.84）扩成 700pt 宽的大面板，并保证完整位于屏幕可视区内（`NotchCapsulePanel.swift:410-484`）。
- 收起态整条胶囊可点击/悬停；展开态内嵌内容：
  - **供应商卡片轮播**：每个已配置连接一枚 `StatusBarProviderTick`（logo + 额度），由 `AgentCarouselDriver` 驱动轮播，悬停暂停；点击卡片选中该账号并回写全局 `selectedConnectionKey`（`AppDelegate.swift:153-157`）。
  - **刷新指示**：`ProviderRefreshState` 四态——idle / loading / success / warning（`NotchCapsulePanel.swift:93-98`）。手动刷新成功后 success 闪烁 2 秒归位；有失败则 warning 粘滞到下次刷新（`AppDelegate.swift:289-303`）。
  - **任务区**：展开态显示活跃 agent 任务（思考中/工作中/待确认…），整块任务信息区点击可跳转到对应 agent 应用（`NotchCapsulePanel.swift:1051-1052`）。

### 2.2 拖拽定位
- 仅**外接（非内建刘海）屏幕**允许水平拖拽面板：`isDraggable = !isBuiltin && isDraggingEnabled`（`NotchCapsulePanel.swift:323`）。
- 拖拽开关与每台显示器的水平偏移量持久化在 `tomo.notchDraggingEnabled` / `tomo.notchDisplayOffsets`（按显示器 persistentID 记忆，`AppSettings.swift:559-577`）。
- 「重置全部刘海位置」可一键回到居中（`StatusBarController.swift:340`）。

### 2.3 显示目标选择
- 设置项 `tomo.notchDisplayTarget`：`auto`（所有带刘海的屏）或 `specificDisplay(id)` 指定某台显示器（`AppSettings.swift:199`）。
- 选定具体显示器后，该屏边缘闪一圈红边作为确认提示（`ScreenHighlightOverlay.flash`，`NotchDisplayManagement.swift:8-41`；触发点 `AppDelegate.swift:63-69`）。
- 显示器热插拔由 `MenuBarNotchDetector` 监听 `screenParametersDidChange` 自动重排面板（`StatusBarNotch.swift:128-151`）；已知显示器名录存于 `tomo.knownDisplays`。

## 3. 分离主窗口（DetachedWindowController）

- **入口**：点击状态栏图标 / 刘海面板展开点击；或设置开启「启动时打开主窗口」（`shouldOpenMainWindowAtLaunch`，即非静默启动，`AppDelegate.swift:196-198`）。
- **内容**：`DetachedUsageWindowView`（额度/供应商/宠物一体的 Companion 仪表盘，`UsageViews.swift:4`）。窗口打开时应用临时切换为 `.regular` 激活策略（获得 Dock 图标与正常焦点行为，`AppDelegate.swift:355-372`）。
- **标题栏控制钮**（`TitleControlsView`，`DetachedWindowController.swift:979`）：
  - **布局方向切换**：竖版/横版仪表盘（`toggleDashboardOrientation`，持久化 `tomo.dashboardOrientation`）。
  - **置顶开关**：窗口始终浮于其他应用之上（`tomo.windowAlwaysOnTop`）。
- 跨 Space/全屏跟随、resize 与换屏逻辑集中在 `windowDidChangeScreen` / `windowDidResize`（`DetachedWindowController.swift:735-754`）。
- 设置窗口 `SettingsWindowController` 与主窗口同构（`DetachedWindowController.swift:821`）。

## 4. 供应商轮播（全局协调）

三层轮播共享同一状态源 `MultiAgentSettingsStore.selectedConnectionKey`：
1. 主窗口 logo 行（`mainWindowProviderCarouselEnabled` 单独开关）。
2. 刘海面板供应商卡（`notchProviderCarouselEnabled` 单独开关）。
3. 轮播间隔 `AccountCarouselInterval`（关闭/5秒/10秒/30秒/1分钟，`AppSettings.swift:84-106`）。
- 仪表盘 hover、弹窗编辑等操作会通过 `setAccountCarouselPaused(source:)` 多源暂停轮播（`AccountCarouselPauseSource`，`MultiAgentSettingsStore.swift:131-145`）。
- 点击已选中的 logo 也会重启计时（注释见 `AppDelegate.swift:153-157`）。
- 刘海面板仅在**全局选中账号真正变化**时才同步索引，避免自动轮播被数据刷新拉回（`lastSyncedProviderSelectionKey`，`StatusBarController.swift:236-239`）。
