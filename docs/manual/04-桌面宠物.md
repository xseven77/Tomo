# 04 - 桌面宠物与伙伴系统

本章介绍 Tomo 的宠物（Pet）精灵动画、与 Codex CLI 的双向同步、独立悬浮宠物窗口，以及伙伴仪表盘（Companion Dashboard）。

---

## 1. 内置宠物与资源格式

App 内置 10 只宠物（`Resources/Pets/<Name>/`）：**BSOD、Codex、Tomo、Dewey、Fireball、Hoots、NullSignal、Rocky、Seedy、Stacky**。

每只宠物两个文件（`PetModels.swift:489-517`）：
- `pet.json`（清单）：仅 4 个字段，例如 Seedy：
  ```json
  { "id": "seedy", "displayName": "Seedy",
    "description": "生机勃勃的小幼苗，伴随你的项目不断萌芽壮大。",
    "spriteVersionNumber": 2, "spritesheetPath": "spritesheet.webp" }
  ```
- `spritesheet.webp`（精灵图）：**硬性网格契约** —— 宽固定 8 列 × 192px = 1536px，高 208px × 行数；行数 ≥9 才被接受（`PetSpriteSheet`，`PetModels.swift:788-804`；校验 `:497-504`）。

### 动画行契约（`PetAnimationContract`，`PetModels.swift:690-762`）
精灵图的每一「行」对应一种动画状态（`PetAnimationState`）：

| 行 | 状态 | 含义 | 帧数/节奏 |
|---|---|---|---|
| 0 | `idle` | 待机 | 6 帧非匀速（280/110/110/140/140/320ms） |
| 3 | `waving` | 挥手（任务完成） | 4 帧 ×140ms |
| 4 | `jumping` | 跳跃（点击互动） | 5 帧 ×140ms |
| 5 | `failed` | 失败/中止 | 8 帧 ×140ms |
| 6 | `waiting` | 等待用户确认 | 6 帧 ×150ms |
| 7 | `running` | 思考/执行中 | 6 帧 ×120ms |
| 8 | `review` | 检查中 | 6 帧 ×150ms |

- 状态切换时先**连播 3 遍反应动画**，再回落到 6 倍慢速 idle 循环（`:721-732`）；系统「减弱动态效果」开启时只渲染首帧（`:717-719`）。
- 点击宠物可触发一次随机 one-shot 互动动作（`PetAnimationPlayer.playOneShot`，`:847-857`；`PetFrameStore.playRandomIdleAction`，`CompanionStores.swift:36`）。
- `spriteVersionNumber`：行数 ≥11 视为 v2（新增 review 等行），否则 v1（`:505`）。

## 2. 活动状态 → 宠物动画映射

宠物动作由统一活动状态机 `CodexActivityState` 驱动（`CodexActivity.swift:39-54`）：

| Agent 状态 | 显示文案 | 宠物动画 |
|---|---|---|
| idle / unavailable | （无） | idle |
| thinking / executing | 思考中 / 工作中 | running |
| reviewing | 检查中 | review |
| waitingForUser | 待确认 | waiting |
| completed | 已完成 | waving |
| interrupted | 已中止 | failed |

数据流：`CodexActivityStore.onSnapshotChanged` → `PetFrameStore.update(pet:activityState:)` → `PetAnimationPlayer`（`AppDelegate.swift:84-101`、`CompanionStores.swift:23`）。

## 3. 自定义宠物与 Codex 双向同步

Codex CLI/桌面版本身支持宠物皮肤，Tomo 与之做了三层联动（`PetModels.swift`）：

1. **宠物目录发现**（`CodexPetCatalog.discover`，`:442-487`）：内置宠物（bundle `Resources/Pets`，id 前缀 `builtin:`）+ 自定义宠物（App Support pets 目录，前缀 `custom:`），官方内置排前。
2. **选中态同步**（`CodexPetSelectionSync`，`:30-120`）：读写 `~/.codex/config.toml` 的 `[desktop] selected-avatar-id`；App 内 ID `builtin:codex` ↔ Codex 内 ID `codex`。
   - 在 Tomo 里换宠物 → 写入 config.toml（`AppSettings.selectedPetID.didSet → syncSelectedPetToCodex`，`AppSettings.swift:443-452`）。
   - 在 Codex 里换宠物 → `CodexPetSelectionMonitor` 监听 config.toml 变化自动刷新（`AppDelegate.swift:182-186`、`PetModels.swift:152`）。
3. **文件级双向同步**（`PetBidirectionalSyncManager.performBidirectionalSync`，`:521-660`）：在 App Support pets 目录与 `~/.codex/pets` 之间互相补齐宠物资源文件夹（正向 forward + 反向 reverse 计数），保证两边宠物库一致；`TomoPetInstaller`（`:325`）负责把 Tomo 宠物安装进 Codex；必要时 `CodexApplicationController.restart()` 重启 Codex 桌面端以生效（`:261-280`）。

## 4. 独立悬浮宠物窗口（StandalonePetWindow）

设置「状态栏与 Pet」中开启 `tomo.standalonePetEnabled` 后，宠物以独立置顶小窗常驻桌面（`AppDelegate.swift:382-395`）。

- **8 向吸附**（`StandalonePetEdge`，`StandalonePetWindow.swift:6-49`）：上/下/左/右/左上/右上/左下/右下；持久化 `standalonePetEdge`。
- **自由拖拽**：直接拖动即进入自由位置（`freeOrigin`，持久化 `standalonePetFreeX/Y`）；自由态下任务弹窗固定朝上展开（`:114-117`）。
- **缩放**：0.8x–1.8x slider（`scaleRange`，`:57`），只缩放宠物本体，任务行尺寸固定（`StandalonePetLayout`，`:53-101`）。
- **点击展开任务栈**：面板宽 316pt，最多显示 4 行任务（`maxVisibleTaskRows`），空态显示占位；点击任务行调用 `openTask(_:)` 跳转对应 agent（`:143`）。
- 窗口为非激活浮窗，切换激活策略（打开主窗口）后会重新排层，代码里多处 re-assert（`AppDelegate.swift:199-205, 360-371`）。

## 5. 伙伴仪表盘（CompanionDashboardViews）

主窗口（DetachedWindow）即伙伴仪表盘（4019 行，`CompanionDashboardViews.swift:4` `CompanionDashboardView`），把宠物、账号与任务融合为一个面板：

- **形象区/承载区**：宠物动画展示 + 点击涟漪与随机动作（`CompanionPetInteraction`，`:2645+`；波纹 `CodexMaterialWave` 系列在 `UsageViews.swift:678+`）。
- **连接 logo 行**：账号轮播与手动选择（`ConnectionLogoRowMotion`、`DashboardConnectionSwitcher`，`:933/:1292`）。
- **额度卡片区**：当前选中 Codex/Gemini 账号的 5h/周窗口、重置券、订阅到期（`CodexUsageSnapshot` 扩展，`:1855`；Gemini 重置时间格式化 `GeminiQuotaResetFormatter`，`:1748`）。
- **本地 Agent 面板**：悬停展开 `CompanionLocalAgentsPanelController` 弹出本地 agent 工作列表（`CompanionLocalAgentRow`，`:2422-2536`）。
- **陪伴统计**（`CompanionStatsStore`，`CompanionStores.swift:60-215`）：按 agent 维度累计工作秒数（`seconds(for agentID)`）、完成任务数，落盘于 App Support，供仪表盘「今日时长/任务数」展示；每秒 tick、退出时结算。

## 6. 视觉品牌资产（BrandAssets.swift）

`BrandAssetID` 提供各供应商/应用的矢量 logo（Codex、Gemini、DeepSeek、OpenCode、Hermes、Pi、Antigravity…），`BrandIconView` 按主题色渲染，用于轮播 tick、仪表盘与 Gateway 各列表（`BrandAssets.swift:4-94`）。
