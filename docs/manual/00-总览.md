# Tomo 操作手册

> 本手册以 `app/Tomo` 源码为准（Package.swift、Sources/ 下 67 个 Swift 文件，约 4.9 万行）整理生成。docs/ 下既有文档可能存在滞后，本手册各章节由代码通读产出生成。

## 应用定位

Tomo 是一款 macOS 菜单栏应用（accessory 模式，无 Dock 图标），用于：

1. **监控多家 AI 供应商的账号额度/用量**（Codex OAuth、DeepSeek、OpenCode 等；统一刷新、自动轮播展示）
2. **监测多个本地 AI Agent 的活动状态**（Codex CLI、Hermes、Pi、DeepSeek Harness、Antigravity；轮询会话文件/SQLite + Unix socket 事件桥双通道）
3. **运行本地 Gateway 网关**（为 Hermes/Pi 等 agent 提供统一模型接入、密钥代理、遥测、调度策略）
4. **桌面宠物 / 伙伴系统**（10 个可选宠物精灵，随 agent 活动状态切换动画；可独立窗口置顶显示）
5. **刘海（Notch）胶囊面板**（在屏幕刘海区显示供应商卡片与实时状态，支持拖拽、多屏选择）
6. **设置中心与自动更新**（主题、刷新间隔、notch 偏移、登录项、GitHub Release 更新检查）

## 工程概况

- **包结构**（`Package.swift`）：两个 Swift 可执行产物 —— `Tomo` 主应用与 `TomoAgentBridge`（agent 事件桥 CLI）。Gateway 本体是独立 Rust 工程（`tomo-gateway`），构建后以 `Contents/Helpers/TomoGateway` 随 app 打包。`CZSTD` 本地 target 封装 zstd（解压 DSH 会话，`Package.swift:14-22`）。
- **最低系统**: macOS 14（Sonoma）。
- **外部依赖**: libzstd （Homebrew)、sqlite3、Security.framework、ServiceManagement.framework（登录项）。
- **打包**: `package_app.sh` / `rebuild_and_run.sh` / `package_local.sh`（注入本机 Gemini OAuth 配置后构建、结束旧进程、打开 dist/Tomo.app）;`release_app.sh` 出 zip/dmg。
- **注册字体**: 启动时将 `Resources/Fonts/carter-one.ttf` 注册进进程（`ApplicationMain.swift:29-39`）。
- **CLI 探测参数**: `--probe-chatgpt-apis` 调用 `CodexUsageService.runChatGPTAPIProbe` 后退出（`ApplicationMain.swift:12-15`）。

## 关键全局单例（AppDelegate 持有）

- `UsageSnapshotStore` / `AppSettingsStore` / `MultiAgentSettingsStore`（多供应商连接与设置）
- `CodexActivityStore` + `AgentEventSocketService`（agent 活动聚合）
- `PetFrameStore` / `CompanionStatsStore`（宠物帧动画与统计）
- `GatewaySupervisor.shared` ← 应用启动即拉起（`AppDelegate.swift:32`)
- `AppUpdateController`（更新检查）

## 分发方式

`.app` bundle：主二进制在 `Contents/MacOS/`，`TomoAgentBridge` 与 Rust 网关 `TomoGateway` 在 `Contents/Helpers/`；Resources 下含 10 个宠物精灵（`Pets/<Name>/{spritesheet.webp,pet.json}`）、`AppIcon.icns`、`github-mark.svg`、`logo.svg`、字体、`GeminiOAuthConfig.plist`（本机构建时注入；仓库内只提交 `.example.plist`）。本机数据根目录：`~/Library/Application Support/Tomo/`（connections-v1.json、gateway-settings.json、agent-events.sock、各凭证目录、Runtimes/Codex/…）。
